    Search Lab

    Four classic algorithms race across the same weighted road graph. Click any map to place the start, click again for the goal. Darker cells were expanded earlier.

    Nodes expanded

    f(n) = g(n) + h(n)

    g(n) is the real road cost from the start. h(n) is the Manhattan distance to the goal, counted in grid blocks.

    Every road weighs at least 1, so h(n) never overestimates. The heuristic is admissible and consistent, which is why A* returns the same optimal cost as UCS while expanding fewer nodes.

    Greedy best-first only looks at h(n): fast, but it can pick a slower road. BFS counts edges, not cost, so it ignores road weights.
